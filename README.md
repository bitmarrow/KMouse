# KMouse

KMouse 是一个使用 Rust 编写的 Windows 键盘鼠标控制工具。进入鼠标模式后，可以使用键盘移动鼠标、点击、滚动，并通过 81 宫格快速定位屏幕位置。

## 功能

- 全局快捷键进入和退出鼠标模式
- 键盘控制鼠标移动和五种鼠标按钮
- 垂直滚轮与水平滚轮控制
- 五档虚拟 DPI 循环切换
- 支持多显示器的 81 宫格快速定位
- 81 宫格使用透明置顶窗口绘制，不会抢占键盘焦点
- 鼠标模式下放行 `Win` 组合键，例如 `Win+D`
- 运行时显示系统托盘图标，图标会区分鼠标模式状态，并可通过右键菜单切换模式或退出程序

## 键位

| 按键 | 功能 |
| --- | --- |
| `Ctrl+M` | 开启或关闭鼠标模式 |
| `↑` `↓` `←` `→` | 移动鼠标 |
| `A` | 左键按下/释放 |
| `S` | 右键按下/释放 |
| `D` | 中键按下/释放 |
| `Q` | 后退侧键按下/释放 |
| `W` | 前进侧键按下/释放 |
| `Z + ↑/↓` | 垂直滚轮 |
| `X + ←/→` | 水平滚轮 |
| `/` | 切换虚拟 DPI |
| `F` | 进入 81 宫格定位 |

DPI 按以下顺序循环：

```text
200 -> 400 -> 800 -> 1600 -> 3200 -> 200
```

程序默认使用 `400` DPI。

## 81 宫格定位

1. 在鼠标模式下按 `F`，屏幕会显示 9 行 × 9 列的 81 宫格。
2. 第一次按 `1-9` 选择行，行号按照从上到下排列。
3. 第二次按 `1-9` 选择列，列号按照从左到右排列。
4. 选择列后，鼠标会移动到最终单元格中心。
5. 按 `Enter` 确认当前位置并退出 81 宫格。
6. 按 `Ctrl+M` 可以随时关闭鼠标模式。

当键盘具有数字小键盘且 Num Lock 已开启时，也可以使用数字小键盘的 `1-9` 输入行号和列号。数字小键盘只会在 81 宫格模式下被拦截。

例如输入 `3`、`7`，表示定位到第 3 行、第 7 列。

```text
第一次数字：行号 1-9
第二次数字：列号 1-9
```

## 构建与运行

需要安装 Rust 工具链，并在 Windows 上运行。

```powershell
cargo run
```

构建发布版本：

```powershell
cargo build --release
```

生成的程序位于：

```text
target/release/kmouse.exe
```

## 权限说明

Windows 会阻止普通权限程序向更高权限窗口注入输入。当任务管理器或其他程序以管理员权限运行时，普通权限启动的 KMouse 可能无法控制它们。

需要控制管理员权限窗口时，请以管理员身份运行 KMouse。安全桌面中的 UAC 提示仍无法由普通桌面程序控制。

## 项目结构

| 文件 | 职责 |
| --- | --- |
| `src/main.rs` | 初始化和 Windows 消息循环 |
| `src/config.rs` | 键位、DPI 和行为常量 |
| `src/state.rs` | 全局运行状态 |
| `src/keyboard.rs` | 全局键盘钩子和按键分发 |
| `src/mouse.rs` | Windows `SendInput` 鼠标事件封装 |
| `src/grid.rs` | 81 宫格几何和多屏坐标计算 |
| `src/overlay.rs` | 透明 81 宫格窗口与绘制 |
| `src/tray.rs` | 系统托盘图标与右键退出菜单 |
